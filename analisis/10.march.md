# Tecnicas estructuraras para el analissi de los requerimientos

* Descompisición funcional
* Especificación via Sentencias textuales
* Modelado del proceso
* Casos de uso
* Checklists
* Inspeccion
* Prototipos

**Descompisición funcional**
Desmenusar el requerimiento principal en partes mas pequeñas.

**Especificación via Sentencias textuales**

Primera columna el requerimiento, en la segunda lo que se necesita y la tercera columna el como se esta viendo

**Modelado del proceso**
Diagrama de flujo pues... pero puedo agregar fechas y horarios.

**Modelo de dominio**
como un Diagrama UML o el de las tablas de una base de datos.

**Checklists**
